# Claude Code configs in large monorepos (≥10k stars)

99 popular repos were sparse-cloned (config files only) and scanned by script. 73 have agent config and **all of them have ≥10k stars**. That was checked with GitHub search, using a `stars:<10000` control that correctly caught `apache/datafusion` (9.5k) and `withastro/starlight` (9.4k), which are excluded. Raw scan: `data/monorepo_scan.tsv` in the task folder; generated table below.

## What the big repos actually do

1. **AGENTS.md is the source of truth; CLAUDE.md points at it.** 63 of 73 have `AGENTS.md`. 22 of the 36 root `CLAUDE.md` files are just `@AGENTS.md` (ruff, sentry, grafana, n8n, mastra, supabase, storybook, strapi, tldraw, pydantic-ai, langflow, lexical, formbricks) or a symlink to it (posthog, cal.com, airflow, superset, prisma, nushell, ToolJet, fluentui, openai-agents-python). One file then serves Claude, Codex, Cursor and Gemini. → **Adopted:** the template writes `AGENTS.md` plus a one-line `CLAUDE.md` importing it. The import form beats a symlink: it works on Windows and leaves room for Claude-only lines.
2. **Root files stay moderate; detail lives next to the code.** Own-content root `CLAUDE.md` has a median of 121 lines, and 30 repos add per-package `CLAUDE.md`/`AGENTS.md` that load only when Claude works in that folder. → **Adopted:** template root ≈ 30 lines, plus guidance to nest per package.
3. **Hooks are few and boring:** dependency install on SessionStart, a formatter on PostToolUse, a guard on PreToolUse.
   - Cloud-gated install: `astral-sh/ruff` and `supabase/supabase` exit early unless `CLAUDE_CODE_REMOTE=true`, then install (`pnpm install`). → **Adopted** as `session-start.sh`.
   - Format after edit: bun (`post-edit-format.js`), payload, prisma, supabase (`format_and_lint.sh`), directus (prettier + eslint + stylelint), vercel/ai (`pnpm fix`). → **Adopted** generically in `stack-core/format.py`.
   - Guard before Bash: bun (`pre-bash-guard.js`), prisma (`enforce-tools.mjs`), tldraw, and dify (`npx -y block-no-verify@1.1.1`, the same `--no-verify` block as our guard). → **Adopted** as `stack-core/guard.py`.
   - Rare but smart: react injects extra instructions only outside `compiler/` (SessionStart + `$PWD` check); superset runs `pre-commit` when Claude runs `git commit` (PreToolUse matcher on the command); tldraw formats changed files on **Stop** (once per turn instead of per edit); twenty uses SessionStart to forbid attribution trailers; prefect symlinks every `AGENTS.md` to `CLAUDE.md` on start.
4. **Allowlists are explicit and read-heavy.** sentry (96 rules), dagster (62), payload (42), nx, prisma, pydantic-ai, n8n: mostly `git log/show/diff`, `gh pr/issue/run view`, `ls/cat/grep/rg`, and the repo's own `pnpm test`/`build`. Only 3 repos use deny rules. → **Adopted:** 102-rule allowlist, with the guard catching the dangerous variants.
5. **Skills over commands and agents.** 23 repos ship `.claude/skills/`, versus 12 with commands and 8 with agents. Skills cost only a description until invoked.
6. **MCP is rare.** Only 10 repos commit `.mcp.json`, and playwright is the only server seen more than once. → **Adopted:** no project MCP by default; playwright comes via plugin.

## Anti-patterns seen

- Root CLAUDE.md files of 300–550 lines that duplicate README and architecture docs (they're paid every turn).
- CLAUDE.md and AGENTS.md maintained separately with drifting content. The import form avoids this.
- Hooks that shell out to `npx -y <pkg>` on every tool call: a network fetch on the hot path.
- Formatters run on every edit across the whole repo instead of on the edited file.
